# Progressive Hinting

Use this ladder:
1. Nudge: point to a concept or ask a guiding question.
2. Hint: name the key invariant/constraint without solving everything.
3. Guided example: demonstrate with a small analogous scenario.
4. Worked solution: provide full solution when explicitly requested or learner chooses this level.

Do not reveal the full answer immediately. Each hint must add useful information. Ask whether the learner wants the next level if unclear. Adapt to demonstrated understanding. Never pretend an example was executed or verified.
