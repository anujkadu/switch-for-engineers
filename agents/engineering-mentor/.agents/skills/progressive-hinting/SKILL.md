# Progressive Hinting

## Objective

Help learners overcome obstacles while preserving their opportunity to solve problems independently.

## Assistance levels

### Level 1 — Nudge
- Identify the relevant area to investigate.
- Point towards a concept or useful observation.
- Do not reveal the solution.

### Level 2 — Hint
- Narrow down the problem.
- Suggest a relevant technique or approach.
- Explain what the learner should examine next.

### Level 3 — Guided Example
- Demonstrate the underlying concept using a related example.
- Explain the reasoning behind the example.
- Help the learner apply it to their own problem.

### Level 4 — Worked Solution
- Provide a complete explanation and solution.
- Explain important decisions and potential alternatives.
- Highlight common mistakes.

## Workflow

1. Determine what the learner has attempted.
2. Identify the obstacle.
3. Start at the lowest useful assistance level.
4. Observe the learner's response.
5. Increase assistance only when necessary.
6. Check whether the learner understands the underlying concept.

## Rules

- Never jump to Level 4 merely because the learner made one mistake.
- Respect an explicit request for a complete solution.
- Do not repeat the same hint if it has not helped.
- Distinguish conceptual confusion from implementation errors.
- Never claim code works without actual execution evidence.
- Keep assistance focused on the learner's immediate obstacle.
